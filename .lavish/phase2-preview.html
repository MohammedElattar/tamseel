المرحلة ٢ — إدخال درجات «مسير الخدمة»

مُحدّثة حسب ملاحظتك: لا حسابات درجات — تُدخَل الدرجة يدوياً تحت كل جدول، ويُحسب المتوسط والنسبة فقط

معاينة قبل كتابة أي كود

ما تغيّر بعد ملاحظتك: أزلت محرك الحساب وجداول تحويل «البيانات → درجة». بدلاً من ذلك: تُعرض بيانات كل مكوّن، وتحته حقل إدخال يكتب فيه المُقيّم الدرجة يدوياً (كالنظام القديم). النظام يحسب فقط المتوسطات (متوسط تقارير الكفاءة) والنسبة النهائية.

الفكرة (مبسّطة)

لكل ضابط، تُعرض بيانات ٧ مكوّنات (الوظائف، التأهيل، تقارير الكفاءة، خدمة التشكيلات، الأوسمة، البعثات، الجزاءات). يكتب المُقيّم درجة كل مكوّن يدوياً (ضمن حده الأقصى). ثم: النسبة = مجموع الدرجات ÷ المجموع الأقصى (≈١٠٥٠) × ١٠٠، وتظهر كبند «مسير الخدمة» في بطاقة التصويت.

جدولان فقط (بدل التسعة السابقة)

score_basis (إعداد لمرة واحدة: أسس التقييم)

الحد الأقصى لدرجة كل مكوّن؛ مجموعها = المجموع الأقصى (≈١٠٥٠).

  • component (jobs, tahil, kafaa, tashkeelat, awsama, ba3asat, gaza)
  • label (اسم عربي)
  • max_degree (الدرجة القصوى)

officer_service_score (لكل ضابط)

الدرجات المُدخَلة يدوياً + المتوسط المحسوب + المجموع والنسبة.

  • officer_id
  • jobs, tahil, kafaa, tashkeelat, awsama, ba3asat, gaza ← إدخال يدوي
  • kafaa_avg ← محسوب (متوسط تقارير الكفاءة)
  • total, pct ← محسوب (المجموع والنسبة)

لا جداول تحويل (score_jobs/score_tashkeelat…) ولا محرك اشتقاق من البيانات الخام — أُلغيت.

شاشة إدخال الدرجات (نظير OFFICERS_TAKYEEM)

لكل مكوّن: بياناته المستوردة + المتوسط (إن وُجد) + حقل إدخال الدرجة. أسفل الشاشة: المجموع والنسبة.

الوظائف — تُعرض الوظائف السابقة (officer_holder_wazayef)، وتحتها الدرجة (حد أقصى ٢٠٠).
تقارير الكفاءة — تُعرض التقارير + المتوسط محسوب تلقائياً، وتحتها الدرجة (حد أقصى ١٧٠).
خدمة التشكيلات — تُعرض المدة/النسبة، وتحتها الدرجة (حد أقصى ١٥٠).
التأهيل — يُعرض (وربما الدرجة المستوردة كقيمة ابتدائية)، وتحته الدرجة (حد أقصى ١٨٠).
الأوسمة والأنواط — تُعرض القائمة، وتحتها الدرجة (حد أقصى ١٤٠).
البعثات — تُعرض القائمة، وتحتها الدرجة (حد أقصى ١٣٠).
المحاكمات والجزاءات — تُعرض القائمة، وتحتها الدرجة (حد أقصى ٨٠).
الإجمالي — المجموع = ∑ الدرجات، والنسبة = المجموع ÷ ١٠٥٠ × ١٠٠ → «مسير الخدمة %».

مخرجات المرحلة ٢ (مبسّطة)

  • جدول score_basis (أسس/حدود قصوى) + شاشة إعداده لمرة واحدة.
  • جدول officer_service_score (درجات مُدخَلة + متوسط + مجموع/نسبة) + هجراته.
  • شاشة «إدخال درجات مسير الخدمة» لكل ضابط: عرض البيانات + حقل درجة تحت كل مكوّن + حفظ.
  • حساب المتوسطات فقط (متوسط تقارير الكفاءة) + المجموع والنسبة تلقائياً.
  • مسار scoring.ts: قراءة/حفظ الدرجات + أسس التقييم.
  • (لا جداول تحويل، لا محرك اشتقاق — أبسط وأسرع.)

أسئلة سريعة قبل التنفيذ

أ) من يُدخل درجات مسير الخدمة؟

ب) أي متوسطات تُحسب تلقائياً؟

ج) درجة التأهيل
