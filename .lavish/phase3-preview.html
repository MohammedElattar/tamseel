المرحلة ٣ — لوحة التحكم (توصيف التقييم)

الشاشة الرئيسية بأربعة تبويبات + بنود التقييم + المرشحون + تسجيل الأعضاء

معاينة قبل كتابة أي كود

١) لوحة التحكم — نظير «تحكم - توصيف التقييم»

شريط علوي ثابت + أربعة تبويبات. نطوّر شاشة CommitteeDetail الحالية لتطابق هذا الشكل.

مسلسل: ١ العام التدريبي: ٢٠٢٦ بداية اللجنة: ٠١-٠١-٢٠٢٦ حذف اللجنة الحالية
الأعضاء بيانات الضباط تحديد بنود العرض ترتيب العرض
الأعضاء — إسم المستخدم / الرتبة / الاسم / الوظيفة / داخل اللجنة (✓). زر «تحميل اللجنة».
بيانات الضباط — مسلسل / الأقدمية / اسم الضابط / لشغل وظيفة (مستوردة، قابلة للتعديل) / تاريخ المقابلة. مجموع الضباط + «اختيار».
تحديد بنود العرض — مسلسل / بند التقييم / الحد الأقصى (تحرير البنود).
ترتيب العرض — تسلسل الضباط للجلسة + منتظر/تم/إخفاء + توصية اللجنة (كما هو تقريباً).

٢) بنود التقييم (تحديد بنود العرض) — الافتراضية

لكل لجنة بنودها الخاصة (حسب ملاحظتك): تُنسخ من قالب افتراضي عند «تحميل البنود»، ويمكن لكل لجنة تعديل بنودها/حدودها. «مسير الخدمة» بند محسوب (قيمته = نسبة المرحلة ٢)؛ الباقي يُدخله العضو أثناء التصويت (المرحلة ٤).

٣) المرشحون (بيانات الضباط)

  • تحميل كل الضباط المستوردين كمرشحين (قرار المرحلة ١) + إضافة/حذف يدوي.
  • لشغل وظيفة مستوردة من عمود ACTIV_NOTE (مثل «ملحق دفاع سول») وتظهر كقيمة افتراضية لكل ضابط — قابلة للتعديل في الجدول.
  • حقل جديد تاريخ المقابلة لكل ضابط.

٤) تسجيل أعضاء اللجنة

  • بحث عن ضابط بالأقدمية / الرقم العسكري / الاسم / الرتبة.
  • إضافته كعضو لجنة بترتيب، مع توليد بيانات دخول.
  • جدول الأعضاء المسجّلين بترتيبهم + حذف.

تغييرات قاعدة البيانات

  • بنود لكل لجنة: قالب افتراضي عام eval_item_template (البنود التسعة، مزروع وقابل للتعديل) + جدول committee_eval_items (committee_id, serial, name, max_degree, kind, source) يُنسخ من القالب عند «تحميل البنود» ويُعدَّل لكل لجنة على حدة.
  • عمود officers.activ_note يستورد «لشغل وظيفة» من ACTIV_NOTE؛ وcommittee_officers.target_job يلتقطها كقيمة افتراضية عند التحميل (قابلة للتعديل)، مع interview_date (تاريخ المقابلة) + هجرة.
  • تعديل «تحميل الضباط» ليحمّل كل الضباط المستوردين (بدون فلترة taraky_c) — تنفيذ قرار المرحلة ١.
