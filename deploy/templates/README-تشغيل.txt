====================================================================
 نظام إدارة لجان تقييم الضباط (Edara) — نسخة تشغيل بدون إنترنت
====================================================================

هذه النسخة جاهزة للتشغيل مباشرة، ولا تحتاج إلى:
  - اتصال بالإنترنت
  - تثبيت Node.js  (نسخة Node مرفقة داخل مجلد node)
  - تشغيل npm install

--------------------------------------------------------------------
طريقة التشغيل
--------------------------------------------------------------------
1) فُك ضغط الملف بالكامل في أي مجلد على الجهاز (مثلاً:  C:\edara ).
2) على ويندوز: انقر نقراً مزدوجاً على  start.bat
   على لينكس:  شغّل  ./start.sh
3) اترك النافذة مفتوحة أثناء استخدام البرنامج.
4) افتح المتصفح على هذا الجهاز على العنوان:
        http://localhost:3000
   ولوصول باقي الأجهزة على الشبكة المحلية استخدم عنوان IP لهذا الجهاز:
        http://عنوان-الجهاز:3000
   (على ويندوز لمعرفة العنوان: افتح Command Prompt واكتب  ipconfig )

--------------------------------------------------------------------
تسجيل الدخول
--------------------------------------------------------------------
  المدير (admin):   اسم المستخدم: admin      كلمة المرور: admin123
  (يُنصح بتغيير كلمة المرور بعد أول دخول)

--------------------------------------------------------------------
البيانات
--------------------------------------------------------------------
  - قاعدة البيانات محفوظة في:  server/data/edara.db
  - لأخذ نسخة احتياطية: أوقف الخادم أولاً ثم انسخ ملف edara.db
  - لبدء قاعدة بيانات فارغة جديدة: أوقف الخادم واحذف ملف
        server/data/edara.db
    ثم شغّل البرنامج مرة أخرى (سيُعاد إنشاؤها تلقائياً بحساب admin).

--------------------------------------------------------------------
إعدادات اختيارية (ملف server/.env)
--------------------------------------------------------------------
  PORT=3000        (لتغيير المنفذ — مثلاً 5173)
  HOST=0.0.0.0     (0.0.0.0 = متاح على الشبكة، أو 127.0.0.1 لهذا الجهاز فقط)
  JWT_SECRET=...    (مفتاح تشفير الجلسات — تم توليده عشوائياً، لا تشاركه)

--------------------------------------------------------------------
ملاحظات
--------------------------------------------------------------------
  - إذا ظهرت رسالة من جدار الحماية (Windows Firewall) عند أول تشغيل،
    اسمح بالوصول حتى تتمكن الأجهزة الأخرى من فتح البرنامج على الشبكة.
  - إذا كان المنفذ 3000 مستخدماً، غيّر قيمة PORT في ملف server/.env.

====================================================================
 English quick start
====================================================================
Offline, self-contained build. No internet, no Node install, no
npm install required (Node is bundled in the "node" folder).

  1. Unzip everything into any folder (e.g. C:\edara).
  2. Windows: double-click  start.bat    Linux: run  ./start.sh
     Keep the window open.
  3. Open  http://localhost:3000  in a browser
     (LAN: http://THIS-PC-IP:3000 — on Windows find the IP with "ipconfig").
  4. Admin login:  admin / admin123  (change the password after first login).

Database file: server/data/edara.db  (stop the server before copying it).
Settings: server/.env  (PORT, HOST, JWT_SECRET).
